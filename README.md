# Sound Capsule

An interactive platform for preserving and exploring real-world soundscapes connected to places, dates and moments in time.

> This project is currently in active development.

## About the project

Sound Capsule combines field recording, interactive maps and digital storytelling to create an accessible archive of everyday soundscapes.

The initial collection focuses on Dublin and includes recordings from parks, streets, public transport and other characteristic locations around the city.

## Current features

- Interactive map for exploring recording locations
- Curated collections of Dublin soundscapes
- Soundscape cards with descriptions, tags and location information
- Persistent audio player
- Responsive layout for desktop and mobile devices
- Visual categories and signature-sound icons
- Original field recordings from locations around Dublin

## Technologies used

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- Native browser audio
- Phosphor Icons
